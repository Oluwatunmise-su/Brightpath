# BrightPath Studio — Beginner React Website

A simple four-page static website built with React, Vite and React Router.

## Pages
- Home
- About
- Services
- Contact

## Requirements
Install Node.js (LTS version), then open this project folder in VS Code.

## Run the website
1. Open the project folder in VS Code.
2. Open the terminal: **Terminal → New Terminal**.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Create a production build
Run `npm run build`. Vite creates the production website files in the `dist` folder.

## Important
This is a static frontend project. The contact form only displays a demo confirmation; it does not send or store messages. There is no database, backend, login system or external API.
